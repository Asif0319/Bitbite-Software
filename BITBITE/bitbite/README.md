# BitBite

BitBite is a web-based health and nutrition management system. It helps users track their daily health activities, create meal plans, manage shopping lists, set health goals, and receive AI-assisted guidance.

## Main Features

- User registration and login
- Personal health profile management
- Food, water, weight, and sleep tracking
- Health-goal management
- Meal planning and calorie tracking
- Automatic shopping-list generation
- Workout and wearable-device records
- AI health coach
- Nutritionist and yoga-coach hiring
- Health research hub

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Project Files

- `index.html` — Main user interface
- `style.css` — Website design and layout
- `script.js` — Frontend functionality
- `backend.php` — Server-side and database operations
- `ai_coach.php` — AI coach functionality
- `test_connection.php` — Database connection test
- `bitbite_xampp_database_setup.sql` — MySQL database setup
- `docs/` — Project report, test report, ERD, and schema diagrams

## How to Run the Project

1. Install XAMPP.
2. Copy the BitBite project folder into the XAMPP `htdocs` folder.
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. Open `http://localhost/phpmyadmin/` in a browser.
5. Import `bitbite_xampp_database_setup.sql` into phpMyAdmin.
6. Open `http://localhost/BitBite/` in the browser.

## Security

API keys and private credentials are not included in this repository. Configure the required API key through a secure environment variable before using the AI coach feature.

## Project Purpose

This project was developed as an academic database and web-development project. Its purpose is to provide several health, nutrition, and fitness-management features in one platform.
