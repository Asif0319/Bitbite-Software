# BitBite

BitBite is a health and nutrition management web application. It helps users
track meals, water, weight, sleep and workouts while creating meal plans,
shopping lists and health goals.

## Main Features

- User registration and login
- Health profile management
- Food, water, weight and sleep tracking
- Meal planning
- Shopping-list generation
- Workout and wearable records
- AI health coach
- Nutritionist and yoga-coach hiring
- Research hub

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Local Setup

1. Install XAMPP.
2. Place the project folder inside `htdocs`.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Import `bitbite_xampp_database_setup.sql`.
6. Open `http://localhost/BitBite/` in your browser.

## Security

API keys and private credentials are not included in this repository.
